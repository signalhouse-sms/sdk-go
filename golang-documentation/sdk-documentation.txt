                    SIGNALHOUSE GO SDK DOCUMENTATION
================================================================================

INSTALLATION
--------------------------------------------------------------------------------
  go get github.com/signalhouse-sms/sdk-go/signalhouse


INITIALIZATION
--------------------------------------------------------------------------------
  import "github.com/signalhouse-sms/sdk-go/signalhouse"

  client, err := signalhouse.NewClient(signalhouse.Config{
      APIKey:  "your-api-token",
      BaseURL: "https://v2.signalhouse.io",
  })
  if err != nil {
      log.Fatal(err)
  }

  Required options:
    - APIKey   (string)  JWT token or service user token for authentication
    - BaseURL  (string)  API base URL

  NewClient returns an error if APIKey or BaseURL is missing.


PER-REQUEST TOKEN OVERRIDE
--------------------------------------------------------------------------------
  Every SDK method accepts an optional *RequestOptions parameter to override
  the default APIKey for that single request.

  Example:
    resp, err := client.Messages.GetMessages(ctx, signalhouse.GetMessagesParams{
        Page:  "1",
        Limit: "10",
    }, &signalhouse.RequestOptions{Token: "user-specific-jwt-token"})

  The per-request token takes precedence over the APIKey provided at
  initialization. The original APIKey remains unchanged.


CUSTOM HEADERS
--------------------------------------------------------------------------------
  Pass additional headers via the RequestOptions.Headers field:

  Example:
    resp, err := client.Numbers.GetPhoneNumbers(ctx, signalhouse.GetPhoneNumbersParams{
        Page:  "1",
        Limit: "20",
    }, &signalhouse.RequestOptions{
        Headers: map[string]string{
            "X-Request-Id": "req_abc123",
        },
    })


IDEMPOTENT REQUESTS
--------------------------------------------------------------------------------
  Set RequestOptions.IdempotencyKey to make a create, update or delete safe to
  retry. The SDK sends it as the Idempotency-Key header. A retry with the same
  key and the same request replays the first response, marked with the
  response header Idempotent-Replayed: true, instead of running the request
  again.

  - Use a new key (a UUID is recommended) for each new operation, and reuse
    it only to retry that exact request.
  - Keys are scoped to the authenticated user and kept for 24 hours.
  - Reusing a key for a different request returns 422; retrying while the
    first request is still running returns 409 with Retry-After.
  - The SDK never creates a key for you. GET requests ignore it, and the
    Voice service does not support it.
  - net/http also resends a keyed request on a dropped connection; the API
    replays it rather than running it twice.

  Example:
    resp, err := client.Subgroups.CreateSubgroup(ctx, signalhouse.CreateSubgroupParams{
        SubgroupData: signalhouse.CreateSubgroupData{GroupID: "G0000001", SubgroupName: "Support"},
    }, &signalhouse.RequestOptions{
        IdempotencyKey: "6f1c2a4e-8b3d-4c5e-9f70-1a2b3c4d5e6f", // a UUID you generate
    })

AUTH  (client.Auth)
--------------------------------------------------------------------------------
  Login(ctx, LoginParams{Email, Password}, *RequestOptions) (*Response, error)
    Login with email and password.

  ResetPassword(ctx, ResetPasswordParams{UserID, NewPassword},
      *RequestOptions) (*Response, error)
    Reset a user's password.

  GetAuthHistory(ctx, GetAuthHistoryParams{GroupID, UserID, Page, Limit},
      *RequestOptions) (*Response, error)
    Get token login history.

  GetOAuthAuthorizationURLWithOptions(provider, OAuthAuthorizationURLParams{
      Next, Email, LinkTicket, ReauthTicket}) (string, error)
    Build the URL that starts an OAuth sign-in (navigate a browser to it; it is
    a redirect, not an API call). provider: "google", "microsoft", "apple" or
    "sso" (Enterprise SSO, requires Email unless ReauthTicket is set). Query
    keys email, linkTicket, next, reauthTicket are added only when set. With a LinkTicket (from CreateOAuthLink) it links
    the provider to the signed-in account instead of signing in; the API then
    returns the browser to /Settings/Security with pendingLink=<ticket> (pass
    it to ConfirmOAuthLink) or linkError. With a ReauthTicket (from
    CreateOAuthReauth) the account signs in again to confirm it's them.
    GetOAuthAuthorizationURL(provider, next) is unchanged and delegates here.

  GetOAuthLinks(ctx, *RequestOptions) (*Response, error)
    GET /auth/oauth/links. List the caller's sign-in methods.
    Returns { passwordKnown, links: [{ provider, email, linkedAt, lastLoginAt }] }.

  CreateOAuthLink(ctx, provider, *RequestOptions) (*Response, error)
    POST /auth/oauth/:provider/link (no body). provider: "google", "microsoft"
    or "apple". Requires a fresh ConfirmTwoFactorIdentity, which it spends.
    Returns { linkTicket, expiresInSeconds }; pass linkTicket to
    GetOAuthAuthorizationURLWithOptions.

  CreateOAuthReauth(ctx, provider, *RequestOptions) (*Response, error)
    POST /auth/oauth/:provider/reauth (no body). provider: "microsoft",
    "apple" or "sso" (not Google, refused with 400), already linked to the account. Spends
    nothing. Returns { reauthTicket, reauthSecret, expiresInSeconds } (keep reauthSecret for the confirm call); pass reauthTicket to
    GetOAuthAuthorizationURLWithOptions. The browser comes back to
    /Settings/Security with a single-use pendingReauth (the session that
    started it redeems it with ConfirmOAuthReauth) or reauthError.

  ConfirmOAuthReauth(ctx, pendingReauth, reauthSecret, *RequestOptions)
      (*Response, error)
    Finish signing in again with a linked provider. Sends a POST to
    /auth/oauth/reauth/confirm with { pendingReauth, reauthSecret }. pendingReauth
    is the
    single-use value (valid 5 minutes) the CreateOAuthReauth round trip returns
    to /Settings/Security with. It counts only for the same account and
    session that started it; 400 when expired or used, 403 for another
    account or session. reauthSecret is the value the create call returned;
    a wrong or missing secret is refused (403) and uses up the re-sign-in.
    Returns: { identityConfirmed } (true when 2FA is off, so it counts as a
    confirmed identity).

  ConfirmOAuthLink(ctx, pendingLink, *RequestOptions) (*Response, error)
    POST /auth/oauth/links/confirm with body { pendingLink }. pendingLink is
    required: the single-use value from the /Settings/Security?pendingLink=...
    redirect that ends the CreateOAuthLink round trip. Links the provider, but
    only for the account the link was started for. Returns the caller's
    { passwordKnown, links: [{ provider, email, linkedAt, lastLoginAt }] }.

  DeleteOAuthLink(ctx, provider, *RequestOptions) (*Response, error)
    DELETE /auth/oauth/:provider/link. provider: "google", "microsoft", "apple"
    or "sso". Requires a fresh ConfirmTwoFactorIdentity. 400 when it is the
    account's only way to sign in. With 2FA on and no password, the last linked Microsoft, Apple or SSO sign-in is refused (400) too. Returns the remaining { passwordKnown, links }.

  Note: ConfirmTwoFactorIdentity also gates CreateOAuthLink, DeleteOAuthLink and
  Groups.SaveSsoConnection / Groups.DeleteSsoConnection. With 2FA off, an account
  without its own password (passwordKnown false) confirms with the code from
  SendTwoFactorIdentityCode(ctx, "email", ...) and Method "email".

BRANDS  (client.Brands)
--------------------------------------------------------------------------------
  GetBrands(ctx, GetBrandsParams{ID, SubgroupID, GroupID, Page, Limit,
      Status, CurrentTollFreeCarrier}, *RequestOptions) (*Response, error)
    List brands with filters.
    CurrentTollFreeCarrier (*bool): with GroupID or SubgroupID, true returns
    only the toll-free brands a new toll-free campaign in that group can use.
    Each toll-free brand carries tollFree.reviewsBusinessOnSubmit: whether
    it's reviewed when it's submitted and keeps its business details from
    then on. When true it also carries tollFree.businessStructure,
    tollFree.industry, tollFree.contactEmail, tollFree.contactJobTitle,
    tollFree.contactJobLevel and tollFree.rejectionReason (why its review
    rejected it, in plain English, or null).

  CreateBrand(ctx, CreateBrandParams{BrandData},
      *RequestOptions) (*Response, error)
    Create a new 10DLC brand.

  CreateTollFreeBrand(ctx, CreateTollFreeBrandParams{BrandData},
      *RequestOptions) (*Response, error)
    Create a new toll-free brand. Sends a POST to /brand/toll-free with
    BrandData as the body; the API sets registrationType to TOLL_FREE.
    Required: SubgroupID, DisplayName, CompanyName, Street, City, State,
    PostalCode, Email, FirstName, LastName, Website and TollFree's
    BusinessRegistrationType, LegalEntityType, TaxID, CountryCode and
    SupportPhone.
    Some groups' toll-free brands are reviewed when they're submitted;
    GetTollFreeRequirements says whether a group's are. Their brands also
    need TollFree's BusinessStructure, Industry, ContactEmail,
    ContactJobTitle and ContactJobLevel, a TollFree.CountryCode of US or CA,
    and a 2-letter State. Any other group gets 400 if it sets
    BusinessStructure, Industry, ContactEmail, ContactJobTitle or
    ContactJobLevel.
    BusinessStructure: CO_OPERATIVE, CORPORATION,
    LIMITED_LIABILITY_CORPORATION, NON_PROFIT_CORPORATION, PARTNERSHIP.
    Industry: AGRICULTURE, AUTOMOTIVE, BANKING, CONSTRUCTION, CONSUMER,
    EDUCATION, ELECTRONICS, ENGINEERING, ENERGY, FAST_MOVING_CONSUMER_GOODS,
    FINANCIAL, FINTECH, FOOD_AND_BEVERAGE, GOVERNMENT, HEALTHCARE,
    HOSPITALITY, INSURANCE, JEWELRY, LEGAL, MANUFACTURING, MEDIA,
    NOT_FOR_PROFIT, OIL_AND_GAS, ONLINE, PROFESSIONAL_SERVICES, RAW_MATERIALS,
    REAL_ESTATE, RELIGION, RETAIL, TECHNOLOGY, TELECOMMUNICATIONS,
    TRANSPORTATION, TRAVEL.
    ContactEmail: the email address of the contact named by FirstName and
    LastName (at most 100 characters). ContactJobTitle: at most 100
    characters.
    ContactJobLevel: DIRECTOR, GM, VP, CEO, CFO, GENERAL_COUNSEL, OTHER.
    A brand reviewed on submit is DCA_PENDING until its business details
    pass review, which usually takes 1–2 business days, then DCA_ACTIVE; if
    they don't pass, it's DCA_REJECTED and tollFree.rejectionReason says
    why. Its business details can't change after it's submitted: UpdateBrand
    refuses (400) a change to CompanyName, Street, City, State, PostalCode,
    Country, FirstName, LastName or TollFree's BusinessRegistrationType,
    TaxID, CountryCode or TaxIDIssuingCountry, and no update takes
    BusinessStructure, Industry, ContactEmail, ContactJobTitle or
    ContactJobLevel. Fix a rejected brand by creating it again with the
    corrections.
    Returns 202: the new brand, in PENDING_CREATION, with a TFNB-prefixed
    brandId.

  GetTollFreeRequirements(ctx, GetTollFreeRequirementsParams{GroupID},
      *RequestOptions) (*Response, error)
    Get whether a group's new toll-free brands are reviewed when they're
    submitted. Sends a GET to /brand/toll-free-requirements/:groupId.
    Returns 200: { groupId, reviewsBusinessOnSubmit }. When
    reviewsBusinessOnSubmit is true, CreateTollFreeBrand needs TollFree's
    BusinessStructure, Industry, ContactEmail, ContactJobTitle and
    ContactJobLevel, a TollFree.CountryCode of US or CA, and a 2-letter
    State; the brand is DCA_PENDING until it's reviewed, and its business
    details can't change after it's submitted.
    Errors: 403 when the caller can't view the group.

TEMPLATES  (client.Templates)
--------------------------------------------------------------------------------
  Versioned templates on /template. Every route is 404 while the API's
  RCS switch is off.
  Every call takes GroupID (query on reads, body on JSON writes, form field on
  upload). Body fields are the raw RcsTemplateBody ({channel: "rcs",
  contentFormat?, content, variables, defaults, fallback}), typed any
  (json.RawMessage or map[string]any) and sent verbatim. contentFormat defaults
  to "content.v1" (content: {blocks}, the only format the API stores and
  returns); "google.rcs" sends Google's RBM AgentContentMessage as content,
  which the API converts. A VIEW_LOCATION suggestion takes latitude/longitude
  or an address the API geocodes.
  Writes honor RequestOptions.IdempotencyKey and apply directly (last write
  wins). 409 codes are TEMPLATE_ARCHIVED, TEMPLATE_NAME_TAKEN, NO_DRAFT
  (publish with no draft) and DRAFT_CHANGED (publish only: the draft changed
  while it was being published; publish again).

  Create(ctx, CreateTemplateParams{GroupID, Name, Tag,
      Body}, *RequestOptions) (*Response, error)
    POST /template. Creates draft version 1; returns 201 {head, version, validation}.
    validation is {valid, errors, warnings}, null when the checks could not run; update returns it too, and
    publish returns {head, version, warnings}. A draft saves even when validation lists errors. On an RCS send, a
    blocked row carries blockReason, reason and issues.

  List(ctx, GetTemplatesParams{GroupID, State, Channel,
      Tag, Search, SortBy, SortOrder, Page, Limit},
      *RequestOptions) (*Response, error)
    GET /template. State DRAFT|PUBLISHED|ARCHIVED, SortBy
    name|createdAt|updatedAt; Limit default 25, max 100. Returns
    {data, total, page, limit} of summaries (head + state, hasUnpublishedChanges).

  Get(ctx, GetTemplateParams{TemplateID, GroupID, Version},
      *RequestOptions) (*Response, error)
    GET /template/:templateId. Version is a positive integer, "draft" or
    "published"; empty returns the published version, else the draft. An
    explicit version never falls back (404).

  Update(ctx, UpdateTemplateParams{TemplateID, GroupID, Name, Tag,
      ClearTag, Body}, *RequestOptions) (*Response, error)
    PUT /template/:templateId. Edits the draft, creating one from the
    published version if needed. Name empty is omitted. Tag nil leaves it
    unchanged; ClearTag sends null. Body is a full replacement.

  Publish(ctx, PublishTemplateParams{TemplateID, GroupID},
      *RequestOptions) (*Response, error)
    POST /template/:templateId/publish. Publishes the current draft.
    An incomplete draft is 400 {code: "TEMPLATE_INVALID", errors, warnings};
    no draft is 409 {code: "NO_DRAFT"}; a draft that changed while it was
    being published is 409 {code: "DRAFT_CHANGED"} (publish again).

  Archive(ctx, ArchiveTemplateParams{TemplateID, GroupID},
      *RequestOptions) (*Response, error)
    POST /template/:templateId/archive. Returns the head.

  Versions(ctx, GetVersionsParams{TemplateID, GroupID, Page, Limit},
      *RequestOptions) (*Response, error)
    GET /template/:templateId/versions. Version summaries, no bodies.

  Validate(ctx, ValidateTemplateParams{TemplateID, GroupID, Body,
      Version}, *RequestOptions) (*Response, error)
    POST /template/:templateId/validate. Set exactly one of Body or
    Version (a numeric Version is sent as a number). Writes nothing; returns
    {valid, contentHash, validatorVersion, errors, warnings}.

  Capabilities(ctx, GetCapabilitiesParams{GroupID, Channel, Provider},
      *RequestOptions) (*Response, error)
    GET /template/capabilities. Channel defaults to "rcs"; Provider
    infobip|sinch adds provider limits and unsupported features.
    Returns the allowed content, limits, time to live ranges (ttlPresets),
    traffic types per use case and iPhone layout numbers (ios).

  GeocodeAddress(ctx, GeocodeAddressParams{GroupID, Address},
      *RequestOptions) (*Response, error)
    GET /template/geocode. Resolves an address to {address, latitude,
    longitude, partialMatch} for a VIEW_LOCATION suggestion. 400
    LOCATION_NOT_FOUND when nothing matches; 429 past the group's lookup
    window; 503 when the server has no geocoding provider.

  UploadMedia(ctx, UploadMediaParams{GroupID, File}, *RequestOptions)
      (*Response, error)
    POST /template/media, multipart fields file + groupId. Returns 201
    {mediaId, groupId, url, bytes, mimeType, kind, width, height, createdAt}.



RCS AGENTS  (client.Rcs.Agents)
--------------------------------------------------------------------------------
  RCS agents under /rcs/agent. An agent links one brand and one campaign, of
  any registration type: the campaign's numbers are its SMS fallback, and the
  brand and campaign supply the company identity and consent text for the
  carrier launch. One brand or campaign can serve many agents. An agent is a
  registration (type RCS_AGENT, AgentID = registrationId "RCSA" + 10
  characters). 404 while RCS is disabled for the environment; 400 while the
  group's rcsEnabled flag is off. To use a new brand and campaign, create the
  brand (Brands.CreateBrand), wait until it is VERIFIED, create the campaign
  (Campaigns.CreateCampaign), then link them.

  The agent: { agentId, groupId, subgroupId, status, registrationStatus,
  stage, brandId, brandRef, campaignId, campaignRef, links, agent, consent,
  useCase, billingCategory, defaultFallback, excludedCarriers, testers,
  contact, testerInvites, carriers, launchable, review, submittedAt,
  approvedAt, history,
  createdAt, updatedAt }. launchable is true
  when the launch request would be accepted now. brandRef and
  campaignRef are the linked records' _ids; brandId and campaignId are their
  current public ids (brandId is null until TCR assigns one). links = {
  brand: { state: OK | NOT_VERIFIED | MISSING, ... }, campaign: { state: OK |
  NOT_ACTIVE | MISSING | NONE, ... } }; a deleted brand or campaign reads
  MISSING. status: DRAFT, PENDING_REVIEW, REJECTED, AGENT_CREATING (approved,
  waiting for the carrier launch), ARCHIVED.

  Agent, Consent and DefaultFallback are typed any: pass an RcsAgentProfile,
  RcsAgentConsent or RcsAgentFallback (empty fields omitted), or a
  map[string]any (a nil value sends null, which clears that field on
  Update). Unset fields are omitted from the body. A nil slice is omitted; an
  empty non-nil slice is sent as [].

  Create(ctx, CreateRcsAgentParams{BrandID, CampaignID, Agent, Consent,
      Contact, UseCase, BillingCategory, DefaultFallback, ExcludedCarriers, Testers},
      *RequestOptions) (*Response, error)
    POST /rcs/agent. Creates a draft (201). BrandID is a carrier brand ID,
    provisional UUID or _id; CampaignID (optional until submit) is a campaign
    ID or _id of that brand. The agent's subgroup is the brand's. Blank
    consent fields fill from the campaign. Required: BrandID

  List(ctx, ListRcsAgentsParams{GroupID, SubgroupID, Status, BrandID,

================================================================================
                          MULTIPART REQUESTS
================================================================================

  The following methods use multipart/form-data automatically:

    - client.Messages.SendMMS(...)
    - client.Messages.SendGroupMessage(...)
    - client.Landings.CreateLanding(...)
    - client.Landings.UpdateLanding(...)
    - client.Brands.SubmitAppeal(...)
    - client.Templates.UploadMedia(...)

  You do not need to construct multipart writers manually. Pass file data
  via io.Reader fields in the params struct and the SDK builds the form
  data internally.


================================================================================
                          QUERY STRING HELPERS
================================================================================

  The SDK automatically constructs query strings from params struct fields.
  Any field with its zero value (empty string, 0) is excluded, so you only
  need to set the filters you care about.

  Example:
    // Only sends ?status=FAILED&page=1&limit=50
    resp, err := client.Messages.GetMessages(ctx, signalhouse.GetMessagesParams{
        Status: "FAILED",
        Page:   "1",
        Limit:  "50",
    }, nil)


================================================================================
                             VALIDATION
================================================================================

  The SDK validates required parameters client-side before making any HTTP
  request. If a required parameter is missing or empty, the SDK returns a
  *ValidationError immediately -- no network request is made.

  Validation errors:
    - Type:    *signalhouse.ValidationError
    - Message: "missing required parameter: <fieldName>"
    - Implements the error interface

  Check with errors.As:
    var valErr *signalhouse.ValidationError
    if errors.As(err, &valErr) {
        fmt.Println(valErr.Field)
    }


================================================================================
                           ERROR HANDLING
================================================================================

  The SDK uses a standardized response format. HTTP errors are NOT returned
  as Go errors -- they are returned as *Response values with Success == false.

  Success response:
    &Response{Success: true, Data: map[...]interface{}{...}, Status: 200}

  Error response:
    &Response{Success: false, Error: "Error message", Status: 400}

  Error types summary:

    Source                    Behavior                         How to Handle
    -----------------------------------------------------------------------
    Missing required param    Returns error (*ValidationError) Check err != nil
    HTTP 4xx/5xx from API     Returns *Response                Check resp.Success
    Network failure           Returns error                    Check err != nil

                       COMPLETE INTEGRATION EXAMPLE
================================================================================

  package main

  import (
      "encoding/json"
      "errors"
      "fmt"
      "log"
      "net/http"
      "os"
      "strconv"

      "github.com/signalhouse-sms/sdk-go/signalhouse"
  )

  func main() {
      client, err := signalhouse.NewClient(signalhouse.Config{
          APIKey:  os.Getenv("SIGNALHOUSE_API_KEY"),
          BaseURL: "https://v2.signalhouse.io",
      })
      if err != nil {
          log.Fatal(err)
      }

      // Send an SMS notification
      http.HandleFunc("POST /api/notify", func(w http.ResponseWriter, r *http.Request) {
          var req struct {
              RecipientNumber string `json:"recipientNumber"`
              Message         string `json:"message"`
              SenderNumber    string `json:"senderNumber"`
          }
          if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
              http.Error(w, "invalid request body", http.StatusBadRequest)
              return
          }

          resp, err := client.Messages.SendSMS(r.Context(), signalhouse.SendSMSParams{
              SenderPhoneNumber:     req.SenderNumber,
              RecipientPhoneNumbers: []string{req.RecipientNumber},
              MessageBody:           req.Message,
              StatusCallbackURL:     fmt.Sprintf("%s/api/delivery-status", os.Getenv("BASE_URL")),
          }, nil)

          var valErr *signalhouse.ValidationError
          if errors.As(err, &valErr) {
              http.Error(w, valErr.Error(), http.StatusBadRequest)
              return
          }
          if err != nil {
              http.Error(w, "internal server error", http.StatusInternalServerError)
              return
          }
          if !resp.Success {
              w.WriteHeader(resp.Status)
              json.NewEncoder(w).Encode(map[string]string{"error": resp.Error})
              return
          }

          json.NewEncoder(w).Encode(resp.Data)
      })

      // Receive delivery status callbacks
      http.HandleFunc("POST /api/delivery-status", func(w http.ResponseWriter, r *http.Request) {
          var status struct {
              MessageID string `json:"messageId"`
              Status    string `json:"status"`
          }
          json.NewDecoder(r.Body).Decode(&status)
          fmt.Printf("Message %s status: %s\n", status.MessageID, status.Status)
          json.NewEncoder(w).Encode(map[string]bool{"received": true})
      })

      // List phone numbers with per-request token override
      http.HandleFunc("GET /api/numbers", func(w http.ResponseWriter, r *http.Request) {
          userToken := r.Header.Get("Authorization")
          if len(userToken) > 7 {
              userToken = userToken[7:] // strip "Bearer "
          }

          page := r.URL.Query().Get("page")
          if page == "" {
              page = "1"
          }
          limit := r.URL.Query().Get("limit")
          if limit == "" {
              limit = "20"
          }

          resp, err := client.Numbers.GetPhoneNumbers(r.Context(), signalhouse.GetPhoneNumbersParams{
              Page:  page,
              Limit: limit,
          }, &signalhouse.RequestOptions{Token: userToken})
          if err != nil {
              http.Error(w, "internal server error", http.StatusInternalServerError)
              return
          }
          if !resp.Success {
              w.WriteHeader(resp.Status)
              json.NewEncoder(w).Encode(map[string]string{"error": resp.Error})
              return
          }

          json.NewEncoder(w).Encode(resp.Data)
      })

      // Get message analytics
      http.HandleFunc("GET /api/analytics", func(w http.ResponseWriter, r *http.Request) {
          q := r.URL.Query()
          resp, err := client.Messages.GetAnalytics(r.Context(), signalhouse.GetAnalyticsParams{
              StartDate:  q.Get("startDate"),
              EndDate:    q.Get("endDate"),
              CampaignID: q.Get("campaignId"),
          }, nil)
          if err != nil {
              http.Error(w, "internal server error", http.StatusInternalServerError)
              return
          }
          if !resp.Success {
              w.WriteHeader(resp.Status)
              json.NewEncoder(w).Encode(map[string]string{"error": resp.Error})
              return
          }

          json.NewEncoder(w).Encode(resp.Data)
      })

      log.Println("Server running on port 3000")
      log.Fatal(http.ListenAndServe(":3000", nil))
  }


REGISTRATIONS AND REGIONAL REPORTING
--------------------------------------------------------------------------------
A registration is what a jurisdiction (or its provider) requires before a sender
may message. One model covers every jurisdiction: `region` is the jurisdiction
(US, GB, CA, AU; any case of "UK"/"GB"/"GBR"/"United Kingdom" is accepted for GB) and `type` selects the shape of `data`.
Types: TEN_DLC_BRAND, TEN_DLC_CAMPAIGN, TOLL_FREE_BRAND, TOLL_FREE_CAMPAIGN,
SHORT_CODE_BRAND, SHORT_CODE_PROGRAM, SHORT_CODE_LEASE (not available), VIRTUAL_LONG_CODE (UK) and ALPHANUMERIC_SENDER_ID (UK). Kinds: identity, program, sender. Channels: tenDLC, tollFree,
shortCode, virtualLongCode, alphanumeric.

Start with the catalog. GET /registration/catalog?region= returns {region,
jurisdiction, sendingRequiresRegistration, registeredThrough, provisioning, types:[{type, kind,
channel, provider, bundles, quantity:{min,max}, requiresParent, available}]}.
registeredThrough is "registration" (use this API), "brandsAndCampaigns" (the US:
register through the Brands and Campaigns APIs) or null (nothing to register, e.g.
Canada). An unlisted country requires registration and offers no types.
Quote and submit only a type whose `available` is true; other types answer 400.

GET /registration/quotes?region=&type=&quantity= (1-100, default 1) returns
{data:[quotes]}, one quote per capability bundle: {capabilities, quantity,
currency, setupAmount, monthlyAmount, totalSetupAmount, totalMonthlyAmount,
etaDays}. Amounts are integer microdollars; setupAmount/monthlyAmount are per
sender and the totals cover the quantity. groupId is optional and staff-only.

Submit on POST /registration (201) with region, type, subgroupId,
capabilities (one of the type's bundles) and data. Set RequestOptions.IdempotencyKey to make a
retry safe (see IDEMPOTENT REQUESTS). Worked example, UK Virtual Long Code: type "VIRTUAL_LONG_CODE",
capabilities ["SMS"] or ["SMS","VOICE"], data {quantity (1-100), useCases (1-10
strings), voice?}. The voice dossier is required exactly when capabilities
include VOICE: companyName, companyPhone, companyWebsite, companyEmail,
address {line1,line2?,city,postalCode,country}, companyDescription,
campaignName, campaignDescription, optInMethods (WEB|KEYWORD|VERBAL),
optOutKeywords (STOP and UNSUBSCRIBE), callTypes (LANDLINE|LOCAL|INTERNATIONAL),
callsPerDay (1-5), callDurationMinutes (1-10, 15, 30, 45 or 60) and termsUrl.

Worked example, UK alphanumeric sender ID: region "GB", type
"ALPHANUMERIC_SENDER_ID", capabilities ["SMS"], data {requestedSenderId (3-11
letters, digits, spaces, dots or dashes; at least one letter), trafficOrigin
(LOCAL: headquartered in the UK | INTERNATIONAL), trafficType (TRANSACTIONAL |
PROMOTIONAL), companyName, companyCountry, companyWebsite (http/https), industry,
messageExample, senderRelationship? (required when requestedSenderId differs from
companyName)}. quantity is always 1; the quote is one ["SMS"] bundle, 6000000
setup and 6000000 monthly by default. Once the registration is APPROVED,
data.phoneNumbers holds the granted sender (e.g. ["ACME"]); pass it as the sender
to send SMS to UK recipients. The server appends "\nOpt out: sihou.io/o/{code}"
to every message from it, counted in segments and in the estimate.

GET /registration accepts groupId, subgroupId, region, type, kind, status,
parentRegistrationId, phoneNumber (filter to registrations holding this phone
number), brandId and campaignId (BrandID / CampaignID: RCS agents linked to that
brand or campaign), sortBy (createdAt (default), subgroupId, registrationId, region or
status), sortOrder (asc or desc (default)), page and limit (max 100) and returns
{data,totalCount,page,limit}.
Region and Status each take one value or a comma-separated list (e.g.
Status: "PENDING_PROVIDER,APPROVED").
GET /registration/:registrationId returns
{registrationId, groupId, subgroupId, region, type, kind, channel, provider,
externalId, parentRegistrationId, status, stage, capabilities, submittedAt,
approvedAt, expiresAt, review:{decision,reviewedAt,reason}, data:{...type
fields}, history:[{status,stage,actor,actorType,timestamp,reason}], createdAt,
updatedAt}. For VIRTUAL_LONG_CODE, data also carries phoneNumbers, the numbers
allocated so far. Statuses: DRAFT, SIGNAL_HOUSE_REVIEW, SIGNAL_HOUSE_APPROVED,
SIGNAL_HOUSE_REJECTED, SUBMITTING, PENDING_PROVIDER, NEEDS_INFORMATION,
PAYMENT_REQUIRED (the setup fee could not be funded; retried hourly), APPROVED,
REJECTED, CANCELLED, PENDING_DELETE, DELETED, EXPIRED, RECONCILIATION_REQUIRED.
`stage` is the provider's step inside a status. Never send from a sender whose
registration is not APPROVED.

DELETE /registration/:registrationId cancels a registration (roles api, admin,
developer, user). Allowed from SIGNAL_HOUSE_REVIEW, SIGNAL_HOUSE_APPROVED,
PENDING_PROVIDER, NEEDS_INFORMATION, PAYMENT_REQUIRED and APPROVED (409
otherwise); a type that keeps drafts (RCS_AGENT) can also be cancelled from
DRAFT and SIGNAL_HOUSE_REJECTED. Numbers already allocated stay on the account
and stop sending.

Drafts (types that keep drafts, such as RCS_AGENT):
UpdateRegistration(ctx, UpdateRegistrationParams{RegistrationID, Data}) sends
PUT /registration/:registrationId with Data as the body to edit a DRAFT or
SIGNAL_HOUSE_REJECTED registration (409 otherwise); Data is required.
ValidateRegistration(ctx, ValidateRegistrationParams{RegistrationID}) sends
POST /registration/:registrationId/validate and returns { valid, errors,
warnings }; it writes nothing. SubmitRegistration(ctx,
SubmitRegistrationParams{RegistrationID}) sends POST
/registration/:registrationId/submit and moves a draft to SIGNAL_HOUSE_REVIEW,
or to SUBMITTING for a type Signal House does not review first (RCS_AGENT,
filed with the provider at once) (400 REGISTRATION_INCOMPLETE with the errors,
409 on a second submit). LaunchRegistration(ctx,
LaunchRegistrationParams{RegistrationID}) sends POST
/registration/:registrationId/launch: an RCS agent the carrier partner holds
in testing goes to SIGNAL_HOUSE_REVIEW, whose approval files the launch (409
unless the agent is in testing, Signal House rejected an earlier request, or
every carrier refused one; 400 REGISTRATION_INCOMPLETE with the errors).

Staff only (the admin namespace exists only when the client enables admin, and
enabling it grants no server permission):
POST /:registrationId/review {action:"APPROVE"|"REJECT",reason?}; REJECT needs reason.
POST /:registrationId/corrections {reason,data} saves the type's correctable
fields (VIRTUAL_LONG_CODE: useCases, voice?) while the provider waits; owner,
quantity, bundle and provider order are fixed.
POST /:registrationId/numbers {phoneNumber} allocates a provider-owned number
through the recovery path.
POST /:registrationId/reconcile {externalId} links the provider order that was
placed after an ambiguous submission; never place a second order to retry.
GET /:registrationId/application?format=json returns {filename,contentType,base64};
decode base64 before saving the document.

Regional reporting: GET /message, /message/analytics, /message/analytics/detail,
/message/analytics/by-subgroup, /message/analytics/by-error-code, /message/dnc and
/message/dnc/analytics accept region and regionScopes; GET
/message/analytics/filter-options accepts region only. region is US, GB or CA
(any case of "UK"/"GB"/"GBR"/"United Kingdom" is accepted for GB) as a single value, a repeated parameter or a CSV.
regionScopes is a JSON array of OR-ed branches {region, channels, brandId?,
campaignId?, phoneNumber?} with channels from tenDLC, virtualLongCode, tollFree,
shortCode and p2p; [] matches nothing and omitting both keeps the existing scope.
Example:
[{"region":"US","channels":["tenDLC"],"brandId":["BUS1"]},
 {"region":"GB","channels":["virtualLongCode"],"phoneNumber":["447400123456"]}]
GET /message always accepts them, as do the analytics and DNC reads.

GetAnalytics, GetAnalyticsDetail, GetAnalyticsThroughput and GetDncAnalytics
accept RegistrationID (a single id or a comma-separated list, like CampaignID):
filter to traffic attributed to these registrations. Except on GetAnalyticsThroughput, which has no
phoneNumber filter, a phoneNumber filter takes precedence. GetPhoneNumbers
accepts a single RegistrationID to list the numbers provisioned under that
registration.

GetAnalyticsBySubgroup, GetAnalyticsByErrorCode and GetDncRecords accept RegistrationID
the same way, with the same precedence. GetMessages accepts
RegistrationID: it filters to messages attributed to those
registrations, and a PhoneNumber filter narrows further. Every method returns 400 when
RegistrationID is combined with CampaignID.

GetAnalyticsFilterOptions returns each phone number with its type (TOLL_FREE,
SHORT_CODE, ALPHANUMERIC, VIRTUAL_LONG_NUMBER, and older local-number spellings) and
country (ISO-2), null when unknown. TOLL_FREE, SHORT_CODE and ALPHANUMERIC are channels
by type; a US number of any other type is 10DLC and a non-US one is a Virtual Long Code.
It also returns Carriers, a plain array of carrier name strings.

UK sending is SMS only, from a +44 virtual long code to GB mobile recipients; MMS
and group MMS are unavailable. POST /message/estimate accepts a +44 sender
(recipients 10-15 digits) and returns region "GB", or "CA" for a Canadian sender.
A READY alphanumeric sender ID (e.g. "ACME") also sends SMS to UK recipients only;
its estimate includes the opt-out footer.
